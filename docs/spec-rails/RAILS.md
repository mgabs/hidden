# Spec-Rails Testing Rails

## Minimum Thresholds
- **Coverage**: $\ge 95%$ line / branch coverage.
- **Mutation Kill Score**: $\ge 95%$ mutation score.

## Supported Stacks
- **TypeScript / Node.js**: Vitest / Jest + Stryker
- **Python**: Pytest + Mutmut
- **Go**: go test + Gremlins
- **Rust**: cargo test + cargo-mutants
